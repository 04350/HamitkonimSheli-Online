# ספריית המתכונים שלי — Hybrid Online

גרסת Windows מקומית, עם שירות עיבוד מקוון לפעולות הכבדות. זו **תוכנת Windows מותקנת**, לא אתר.

## עקרונות המערכת

- ממשק Tkinter בעברית, RTL, מבוסס על תוכנת Windows המקורית.
- מסד הנתונים, תיקיות המתכונים, קובצי המקור, קטגוריות, תגיות, מועדפים, דירוגים, היסטוריה וגיבויים נשמרים במחשב.
- סריקת OCR בעברית ובאנגלית מתבצעת בשרת.
- המרת קובצי Office ל-PDF מתבצעת בשרת.
- קובץ נשלח לשרת רק כאשר המשתמש מפעיל סריקה או המרה. אין סנכרון אוטומטי של כל הספרייה.
- התוכנה יכולה לפתוח ולנהל את הספרייה המקומית ללא אינטרנט. OCR והמרת Office דורשים חיבור.
- נתוני המהדורה ההיברידית נשמרים בתיקייה מקומית נפרדת מזו של המהדורה הלא-מקוונת.

## התקנת תוכנת Windows

הורידו את חבילת Windows מ-GitHub Actions (Artifacts), חלצו והפעילו את קובץ ה-EXE. אין צורך ב-Python או בהתקנת ספריות במחשב המשתמש.

## שירות העיבוד המקוון

השרת נמצא בתיקיית service ומשתמש ב-FastAPI, Tesseract (עברית + אנגלית) ו-LibreOffice. הוא אינו שומר קבצים שהועלו: כל קובץ מעובד בספרייה זמנית, שנמחקת בסיום הפעולה או לאחר שליחת ה-PDF.

### פריסה ב-Render

1. פתחו את Render וחברו את חשבון GitHub.
2. בחרו New → Blueprint.
3. בחרו את המאגר 04350/HamitkonimSheli-Online.
4. Render יקרא את render.yaml ויקים את hamitkonimsheli-online-api.
5. לאחר שהפריסה מסתיימת, פתחו את כתובת השירות ואת /health. צריך לקבל status: ok, ocr: true, office: true.
6. כתובת ברירת המחדל בתוכנה היא https://hamitkonimsheli-online-api.onrender.com. אם Render מקצה כתובת אחרת, עדכנו אותה בהגדרות התוכנה.

**חשוב לגבי תוכנית Free:** שירות חינמי ב-Render עשוי להיכנס למצב שינה אחרי 15 דקות ללא פעילות, והבקשה הראשונה אחר כך עלולה להמתין כדקה. זו סביבת התחלה/בדיקה ולא התחייבות לזמינות רציפה. שירות OCR כבד יותר עשוי להזדקק לתוכנית עם זיכרון ומשאבים נוספים.

## נטפרי

אין שימוש ב-CDN, Google Fonts, שירות OCR חיצוני או שירותי ענן של צד שלישי מתוך התוכנה. התקשורת היא HTTPS ישירה מול כתובת ה-API. עם זאת, לא ניתן להבטיח מראש שכתובת Render תהיה פתוחה בנטפרי: לאחר פריסה יש לבדוק את הדומיין המדויק מתוך חיבור נטפרי, ואם נחסם — לשלוח בקשת פתיחה לנטפרי. בדיקת CI אינה בדיקת סינון נטפרי.

## פרטיות ואבטחה

- הספרייה המקומית אינה מועתקת לענן.
- רק הקובץ שנבחר לסריקה/המרה נשלח לשרת, לצורך הפעולה שביקש המשתמש.
- השרת מגביל גודל קובץ, בודק סוגי מסמכים, מגביל קצב בקשות ומוחק קבצים זמניים.
- אין בשרת משתמשים, חשבונות, ספריית מתכונים או אחסון קבוע.
- אין להעלות קובצי מסמכים רגישים אם המשתמש אינו מסכים לעיבוד שלהם בשרת.

## בדיקות

- בדיקות יחידה של התוכנה המקומית.
- בדיקות לקוח API ותקינות כתובת HTTPS.
- בדיקות FastAPI ל-health, קבלת תמונה, תשובת OCR, קובץ פגום וסינון סוגי Office.
- בדיקת מנועי Tesseract עברית/אנגלית ו-LibreOffice ב-GitHub Actions.
- בניית EXE והרצת smoke test ב-Windows.

שיתוף מתכונים דרך קישור ציבורי דורש שכבת אחסון והרשאות נפרדת, ולכן אינו מופעל בגרסה זו. הוא יתווסף רק לאחר תכנון הרשאות, תפוגת קישורים ואחסון קבוע. שרת העיבוד הנוכחי הוא stateless ואינו משמש לאחסון המתכונים.
