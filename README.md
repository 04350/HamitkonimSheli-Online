# ספריית המתכונים שלי — Hybrid Online

מהדורת Windows מקומית לניהול מתכונים וקבצים, עם אפשרות לחיבור לשירות עיבוד מקוון עבור OCR והמרת Office. זו **תוכנת Windows**, לא אתר.

## הורדה והתקנה

**[הורדת הגרסה האחרונה למחשב Windows](https://github.com/04350/HamitkonimSheli-Online/releases/latest)**

1. הורידו את קובץ ה־ZIP מעמוד Releases.
2. חלצו אותו לתיקייה במחשב.
3. הפעילו את קובץ ה־EXE.

אין צורך להתקין Python או ספריות נוספות. קובץ ההתקנה הוא נייד, ואינו דורש מתקין נפרד.

## מה אפשר לעשות גם בלי שרת?

הספרייה המקומית פועלת ללא אינטרנט:

- ניהול מתכונים, מסמכים וקבצים.
- ייבוא קבצים ותיקיות, כולל שמירה על מבנה תיקיות.
- חיפוש לפי שם ותוכן שחולץ מקומית.
- קטגוריות, תגיות, מועדפים, אוספים, דירוגים והיסטוריה.
- עריכת מתכונים, התאמת כמויות, רשימות קניות ומצב בישול עם טיימרים.
- הדפסה והפקת חוברות.
- סל מחזור, גיבוי ושחזור.
- תצוגה של תמונות, PDF, טקסט ופורמטים נוספים הנתמכים מקומית.

מסד הנתונים, תיקיות המתכונים, קובצי המקור, ההגדרות והגיבויים נשמרים במחשב. נתוני המהדורה ההיברידית נשמרים בתיקייה נפרדת מהמהדורה הלא־מקוונת המקורית.

## פעולות שמצריכות שרת עיבוד

המהדורה כוללת לקוח מוכן לשירות עיבוד מקוון עבור:

- OCR בעברית ובאנגלית מתוך תמונות.
- המרת מסמכי Word, Excel ומצגות ל־PDF.

**לתשומת לבכם:** חבילת התוכנה אינה כוללת שרת ציבורי פעיל. עד שמגדירים כתובת של שרת עיבוד שנפרס ונבדק, פעולות OCR והמרת Office דרך השירות המקוון לא יהיו זמינות. אפשר להשאיר את שדה כתובת השרת ריק ולהמשיך להשתמש בכל שאר יכולות הספרייה המקומית.

כאשר שירות כזה יוגדר, התוכנה תשלח קובץ לשרת רק בעת הפעלת פעולת OCR או המרה. אין סנכרון אוטומטי או העלאה של כל הספרייה.

## הגדרות שירות העיבוד

בהגדרות התוכנה ניתן להזין כתובת HTTPS של שירות עיבוד וללחוץ על **בדיקת חיבור**. כתובת ריקה משביתה את הפעולות המקוונות בלבד ואינה משפיעה על ניהול הספרייה המקומית.

כתובת ברירת מחדל אינה מוגדרת בכוונה, כדי שהתוכנה לא תנסה להתחבר לשרת שעדיין לא הוקם.

## פרטיות ואבטחה

- הספרייה המקומית נשמרת במחשב.
- אין צורך בחשבון משתמש או בהרשמה.
- לא מתבצע סנכרון אוטומטי לענן.
- לפני הפעלת OCR או המרת Office, מוצג שהקובץ שנבחר יישלח לשירות העיבוד.
- שירות העיבוד בקוד המקור מיועד להיות stateless ולמחוק קבצים זמניים לאחר הפעולה; יש לוודא את הגדרות השירות בפועל לפני שימוש בקבצים רגישים.

## גיבוי ושחזור

מומלץ להפעיל גיבוי אוטומטי בהגדרות ולשמור מדי פעם עותק גיבוי נוסף מחוץ למחשב. מנגנון השחזור שומר על מבנה התיקיות של הקבצים ומבצע בדיקת תקינות למסד הנתונים לפני החלפת הספרייה הקיימת.

## בדיקות ופיתוח

- בדיקות יחידה לתוכנה המקומית ולקוח השירות.
- בדיקות בניית EXE והפעלה ב־Windows.
- צילום מסך אוטומטי של התוכנה לאחר הפעלה עם נתוני הדגמה.
- בדיקות API ומנועי OCR/Office בסביבת CI. בדיקות אלה אינן מעידות ששרת ציבורי נפרס או שדומיין מסוים פתוח בנטפרי.
