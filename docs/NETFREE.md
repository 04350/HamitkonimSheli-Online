# בדיקת תאימות לנטפרי

1. פרסמו את השירות ב-Render.
2. פתחו מתוך חיבור נטפרי את https://hamitkonimsheli-online-api.onrender.com/health.
3. אם מופיע עמוד חסימה, שלחו לנטפרי בקשת פתיחה עבור הדומיין המדויק.
4. לאחר פתיחה, בתוכנה היכנסו להגדרות → שירות עיבוד מקוון → בדיקת חיבור.
5. בדקו סריקת JPG, סריקת PDF סרוק והמרת DOCX.

אין להכריז על תאימות לנטפרי לפני בדיקה בפועל מתוך רשת נטפרי. שירות Render חינמי יכול להירדם אחרי 15 דקות ללא בקשות, ולכן בדיקת החיבור הראשונה לאחר שינה עשויה לקחת זמן.
