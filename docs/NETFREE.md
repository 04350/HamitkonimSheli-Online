# בדיקת תאימות לנטפרי

## לפני פריסת שירות עיבוד

בגרסה הנוכחית אין שרת עיבוד ציבורי פעיל שמסופק עם התוכנה. לכן אין עדיין דומיין תקין שאפשר לאשר בנטפרי. השארת כתובת השירות ריקה מאפשרת להמשיך להשתמש בספרייה המקומית.

## לאחר שתיפרס כתובת שירות

1. פתחו מתוך חיבור נטפרי את `https://<כתובת-השרת>/health`.
2. ודאו שמתקבלת תשובת JSON תקינה, עם `status: ok`, `ocr: true` ו־`office: true`.
3. אם מופיע עמוד חסימה, שלחו לנטפרי בקשת פתיחה עבור הדומיין המדויק.
4. לאחר פתיחה, בתוכנה היכנסו להגדרות → שירות עיבוד מקוון → בדיקת חיבור.
5. בדקו סריקת JPG, סריקת PDF סרוק והמרת DOCX.

אין להכריז על תאימות לנטפרי לפני בדיקה בפועל מתוך רשת נטפרי. שירות Render חינמי יכול להיכנס למצב שינה, ולכן בדיקת החיבור הראשונה לאחר שינה עשויה לקחת זמן.
